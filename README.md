# Gerry-the-intersting-creature

I made a statue/sculpture of a wierd creature named Gerry
This was made in fusion 360
To make it I had to learn how to use the circular pattern tool because otherwise it would have taken forever to place all the teeth and petals on the flower. Other than that there were no problems. 
This is a statue so if you want to use you just need to 3d print it!<p>

This is the file on printables-
https://www.printables.com/model/1893676-gerry-the-monster-statue
You can download and print it if you want a Gerry in your house

<h2>This is Gerry!</h2>

This sculpture has a head, two arms, two legs, a super muscular body and a little monster flower buddy.

In order to make this I had to learn how to use the circular pattern tool, how to make a monster flower not a normal one(add teeth and more monster characteristics) and the text tool in the sketch menu

<h1>BOM:</h1>

-3D printer fillament to print the file
-Or a printer league grant to print it
